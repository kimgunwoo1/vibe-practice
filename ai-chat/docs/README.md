# docs — RAG용 공식 문서

상담 챗봇이 답변의 근거로 쓸 공식 문서를 넣는 곳입니다.

## 넣을 문서

- 장애인활동지원: 보건복지부 「장애인활동지원 사업안내」
- 장애인근로지원: 한국장애인고용공단 근로지원인 사업 지침

## 파일 이름

분야와 기준 연도를 붙입니다. 답변에 출처와 연도를 표시할 때 씁니다.

```
activity-2026-장애인활동지원-사업안내.pdf
work-2026-근로지원인-사업지침.pdf
```

- 앞부분은 분야입니다. `activity`는 활동지원, `work`는 근로지원입니다.
- 새 연도의 문서가 나오면 새 파일을 넣고, 지난 연도 파일은 지운 뒤 다시 적재합니다.

## git에 올리지 않음

PDF는 용량이 커서 `.gitignore`로 제외합니다. 원본은 Google Drive에 두고, 새 컴퓨터에서는 Drive에서 받아 이 폴더에 넣습니다.

| 파일 | 원본 |
| --- | --- |
| `activity-2026-장애인활동지원-사업안내.pdf` (489쪽) | Drive: `2026년+장애인활동지원+사업안내.pdf` |

## 표 정리

표가 있는 쪽은 `npm run convert-tables`로 Claude에게 줄글로 바꿔 `converted/<PDF 이름>.json`에 저장합니다. 이 JSON은 git에 올립니다. 새 PDF를 넣으면 적재 전에 먼저 실행합니다.

## 적재

`npm run ingest`(`scripts/ingest.ts`)가 이 폴더의 문서를 잘게 나누고 임베딩해서 MongoDB Atlas Vector Search에 넣습니다. 자세한 내용은 `../CLAUDE.md`의 "RAG" 절을 봅니다. 목차와 전년도 비교표 쪽은 적재하지 않습니다.
